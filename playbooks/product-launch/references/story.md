# Story: what the video says, in what order

A website is an information layout. A launch video is an emotional sequence. Reorder, merge and drop the site's
content freely; build everything around one promise.

## 1. Extract the product truth

Write these six lines before any frame:

- **Audience:** who it speaks to ("startup operators who live in Notion").
- **Pain or desire:** what they already want fixed or want to have.
- **Promise:** the one line the whole video proves ("Teams and agents work in one place").
- **Product role:** what the product does in that story.
- **Proof:** the UI moments, metrics, customer logos, demos you actually have.
- **CTA:** what to do next (URL, "Try it free", install command, waitlist).

## 2. Pick one arc

| Arc | Use when | Frame order |
| --- | --- | --- |
| Problem → platform | The pain is known (scattered tools, busywork) | hook (pain) → name → hero → 2–3 features → proof → CTA |
| Demo loop | The UI explains itself | question → name → demo 1 → demo 2 → trust → CTA |
| Before / after | It replaces an old workflow | before → after tease → name → step 1 → step 2 → wow → CTA |
| Feature cascade | Many capabilities, status-driven | category hook → feature → benefit → feature → benefit → climax → CTA |
| Future pacing | A new category | imagine → name → pain gone → how → outcome → CTA |

Translate every feature into what the viewer gets. Never stack raw features.

The Notion demo is problem → platform: "Docs here. Chats there. Tasks everywhere." → logo and headline on the drop →
hero video → capture / ask / agents → use-case roll → logos and stats → CTA.

## 3. Frame roles

One job per frame: `hook`, `pain`, `product_intro`, `feature`, `benefit`, `proof`, `cta`.

- **Hook (3–4 s):** tension, curiosity or desire, in the viewer's words. Options: a pain in three beats, a rhetorical
  question, one big number, a "could be X, or Y, or Z?" cycle, direct address, a visual spectacle. Never open with a
  company description.
- **Product intro:** the name lands on the music drop. Logo + one-line claim, then straight into the real product.
- **Feature:** a short sequence on the real surface: input → action → result → one line of value. A feature that
  depends on a workflow gets 2–3 consecutive frames on the same surface.
- **Proof:** customer logos the product itself shows, real metrics counting up, a quote with a name.
- **CTA:** logo lockup, one line, one action (button with a drawn cursor click, URL, install command). Hold it.

## 4. Line shapes that work (from launch videos that performed)

Write each headline or voiceover line in one of these shapes. Swap in the product's words.

**Hook**
- Pain in beats: "Docs here. Chats there. Tasks everywhere."
- Escalating jab: "Getting traffic is hard. Insanely hard."
- Option cycle then crash: "A doc? A database? A wiki? It's all of them."
- One stat cold open: "One million users. Ninety days."
- The ask itself: "What if you could just… ask?" (a prompt box types it)
- Roll-call: "For founders, for designers, for marketers. For anyone who ships."

**Product intro**
- "Introducing [Name]. [What it is in 4 words]."
- Name only, the mark assembling on the drop.
- "This is [Name]. Click through and watch your work change." (cursor-led first look)
- "Open a space, drop in your notes, hit share. That's it."

**Feature**
- One workflow end to end: "Pick your recipient, set your intention, choose a tone. Done."
- One ask, one answer: "Ask for revenue by region. The chart draws itself."
- The machine working: "It checks every file, flags what's broken, fixes what it can."
- Breadth at once: "Command bar, API, SSO, version history. And a lot more."
- Cause and effect: "Drag the value. The button follows."

**Benefit**
- Staccato value montage: "No setup. Every model. Clean UI. Fast."
- Calm value title: "A smart color picker. With instant shades."
- Demo / value line / demo: "Watch it draft the reply. That's an hour back."

**Proof**
- "Trusted by teams that ship." + logo wall + 3 stats counting up.
- "Loved by 1,000+ teams." on a clean card.

**CTA**
- "Try it free. No credit card. name.com"
- "This is [Name]. Start building. It's free."
- An install command typed in a pill: `npx -y name install`.

Vary the shapes across the video; don't reuse the same one on consecutive frames.

## 5. Voiceover (only when the user wants one)

- 1–2 short sentences per frame, written in cues ("Content, sentiment, engagement. In one place.") so each
  on-screen piece can appear when its word is spoken.
- Concrete verbs, the viewer as "you". Avoid "seamless", "unlock the power of", "streamline your workflow".
- User script given verbatim: don't change words; split at sentence or clause boundaries.
- Voice: the user's own recording first; a free local voice (Kokoro, Piper) second; paid voices only with a budget.

## 6. Storyboard frame template

```md
## Frame 3 — Product hero
- scene: the real hero video rises in a floating window, headline above
- duration: 6s (bars 5–7)          voiceover: ""
- transition_in: cut
- type: product_intro               persuasion: show, don't tell        beat: wow
- assets: assets/ui/hero.mp4 (11 s, agents moving cards); assets/ui/hero-first-frame.png
- keyMessage: the product does real work
```

## Checklist
- The promise is one line and lands by frame 2.
- The hook works muted in 3–4 s.
- Each frame has one job; features are shown working, not listed.
- Every claim, stat and logo has a real source.
- Frame lengths are whole bars on one tempo; drops are marked.
