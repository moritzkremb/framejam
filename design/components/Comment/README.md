# Comment

There is one kind of comment, and it belongs to the version it was written on.

- **On the open version** (the latest one, before you send): a lime number dot (the same number as its pin on the video), the time in mono or *Whole video*, and the text. Click it to jump the video there. ⋯ has *Edit* and *Delete*.
- **On a sent version** (including the one you just sent): the same comment, greyed and read-only. Nothing to manage.
- Live comments add one quiet line naming the element and its animation, which tells the agent exactly what to change.

Comments never carry a state like "sent", "open" or "fixed". Only the version has a state: open or sent.
