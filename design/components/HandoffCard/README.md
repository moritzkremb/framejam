# HandoffCard

What replaces the comment box once you press Send. The version is now sent and locked, and this card sits exactly where you just clicked, saying whether your agent got the comments.

- **Agent wasn't listening** (lime outline): "Sent. Now tell your agent." It shows the sentence to paste into your chat (with the review id) and a primary Copy button. It turns into the next card by itself as soon as the agent picks the comments up.
- **Agent has them**: "Your agent is making version 3." The page switches to version 3 when it arrives, and version 3 opens with an empty list and the comment box back.

Why it exists: an agent can only receive comments while it's waiting for them. Once its turn in the chat has ended, nothing can push a message in, so you need to be told to ask.
