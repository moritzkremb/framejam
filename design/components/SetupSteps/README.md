# SetupSteps

The first-run checklist on the home screen. It replaces the always-on "Connect your agent" card and the "How the loop works" text.

Three steps with a connecting line: **Connect your agent**, **Pick a style**, **Ask for a video**. Steps tick themselves off (green check) as the server sees an MCP connection, a selected style, and a first review. The current step is inverted and holds the one action. Once a review exists, the checklist collapses to a single *Connected to Claude Code* line.
