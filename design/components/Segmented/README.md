# Segmented

A pill toggle for two to four options that switch a view in place: the home switch (*Reviews / Styles*) and style format (*All · 16:9 · 9:16 · 1:1*). The chosen option lifts onto `bg` with `shadow-sm`.

Don't use it for choices that need explaining (that's a popover with descriptions, like SourceSwitch) or for filtering comments (they are grouped instead).
