# ReviewCard

A review in the list, led by the one thing that matters: whose turn it is.

The poster keeps the video's own shape (tall for 9:16, wide for 16:9). Then the name, a coloured **state line**, and quiet metadata (version · style · time).

State lines, in priority order: *Waiting for your feedback* (blue: the agent is blocked on you), *N comments not sent* (lime), *Agent is working* (blue spinner), *All done* (grey). Reviews waiting on you sort first.
