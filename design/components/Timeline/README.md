# Timeline

A filmstrip of the video's frames that you can scrub, click, or drag across.

- **Click** to jump; **drag across** to select a range (lime outline with handles), which attaches that range to the comment box.
- The lime playhead runs through the strip; frames already played dim slightly.
- Comment markers float above the strip: lime for yours, grey for sent, numbered like the pins.
- Only start and end times are printed underneath; hovering shows the time under the cursor.
